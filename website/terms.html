What the installer does

  • It installs Mergelio and nothing else: no toolbars, browser extensions, adware or other bundled software.
  • It does not change your browser, search engine, home page or system settings.
  • Mergelio works with Git that is already installed on your computer and only touches the repositories you open in it. What it does with data is described in the privacy policy.

Official downloads

  • Mergelio is distributed only from this website and from GitHub Releases. Every download link on mergelio.com points to a file in those releases.
  • The macOS app is signed with an Apple Developer ID and notarized by Apple. The Windows installer is signed with a Certum code signing certificate issued to Serhii Kotenko.
  • Each release publishes SHA-256 checksums in SHA256SUMS.txt, with a signature in SHA256SUMS.txt.asc. See how to verify a download.
  • Copies from other sites are not made by us. If you got Mergelio elsewhere, compare its checksum before running it.

Updates

The app checks the project's update feed on GitHub to see whether a new version exists, and downloads updates only from GitHub Releases.

Uninstalling

  • Windows: Settings → Apps → Installed apps → Mergelio → Uninstall.
  • macOS: quit Mergelio and move it from Applications to the Bin.
  • Linux: remove the mergelio package with your package manager.

Uninstalling does not touch your repositories.
